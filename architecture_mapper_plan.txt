ARCHITECTURE MAPPER — IMPLEMENTATION PLAN
==========================================

TECH STACK OVERVIEW
-------------------
Language:        TypeScript (Frontend + Backend)
Frontend:        React + Vite
Backend/Proxy:   Node + Express (Hides your API key)
Database:        Supabase (Postgres) — Free tier available
Auth:            Supabase Auth (Google / email login)
AI:              Anthropic API — claude-sonnet-4
Storage:         Supabase Storage (Exports, PDFs)
Hosting:         Vercel — Free tier, zero config
Caching:         Upstash Redis — Rate limits + cache
Styling:         Tailwind CSS — Utility-first, fast
Error Tracking:  Sentry — Free tier
CI/CD:           GitHub Actions — Auto deploy on push


===========================================================
PHASE 1 — PROJECT SETUP & SCAFFOLDING                Day 1–2
===========================================================
Tags: TypeScript, Vite, Express, Git

Steps:
  • Init repo         — npm create vite@latest mapper --template react-ts
  • Install deps      — Tailwind, React Router, Supabase client, Axios
  • Folder structure  — /src/components, /src/api, /src/hooks, /src/types
  • Backend scaffold  — /server folder with Express + TypeScript, ts-node for dev
  • Env vars          — .env.local for ANTHROPIC_API_KEY, SUPABASE_URL, SUPABASE_ANON_KEY
  • Deploy skeleton   — Connect GitHub repo to Vercel, add env vars in dashboard

Prompt: "Give me the folder structure and package.json to start"


===========================================================
PHASE 2 — API PROXY (BACKEND)                        Day 3–4
===========================================================
Tags: Node.js, Express, TypeScript, Upstash Redis

Steps:
  • POST /api/generate  — Receives idea + project type + scale, calls Anthropic API,
                          returns JSON arch
  • API key protection  — Key lives only on server, never sent to browser
  • Prompt engineering  — Build the system prompt that returns structured arch JSON
                          (layers, improvements, techStack)
  • Rate limiting       — Upstash Redis middleware: 10 requests/hour per IP or user
  • Error handling      — Wrap Anthropic call in try/catch, return typed error responses
  • POST /api/refine    — Takes existing arch + user feedback, returns refined arch
                          with version bump

Prompt: "Write the Express proxy server code for the Anthropic API call"


===========================================================
PHASE 3 — AUTH + DATABASE                            Day 5–6
===========================================================
Tags: Supabase, Postgres, Auth, RLS

Steps:
  • Supabase project    — Create project at supabase.com, get URL + anon key
  • Supabase Auth       — Enable Google OAuth + email/password in Supabase dashboard
  • DB schema           — Tables: users, architectures (id, user_id, title, json_data,
                          created_at, version), feedback_log
  • Row-level security  — Users can only read/write their own architectures
  • Save architecture   — After each generation, auto-save to Supabase with upsert
  • History endpoint    — GET /api/history returns last 20 architectures for logged-in user

Prompt: "Write the Supabase schema SQL and RLS policies for this app"


===========================================================
PHASE 4 — CORE UI                                   Day 7–10
===========================================================
Tags: React, Tailwind, TypeScript, Vite

Steps:
  • Idea input          — Textarea + project type select + scale select + generate button
  • Architecture display — Layer cards grid (icon, name, feature list), tech stack panel,
                           improvements list
  • Feedback bar        — Input + refine button, appears after first generation
  • History sidebar     — List of past architectures, click to reload
  • Version badge       — v1 → v2 → v3 as user iterates
  • Loading skeletons   — Pulse animation while API call is in flight
  • Error toast         — Surface API errors cleanly to user

Prompt: "Build the architecture card grid component in React with Tailwind"


===========================================================
PHASE 5 — LEARNING SYSTEM                          Day 11–12
===========================================================
Tags: Postgres, Prompt Engineering, Supabase

Steps:
  • Feedback logging      — Every refinement request saved to feedback_log table
                            with arch_id + message
  • Mistake memory        — Last 8 user feedbacks injected into system prompt as
                            'lessons learned'
  • Per-user preferences  — Store preferred project types, scale, past tech stacks
                            in Supabase
  • Suggestion chips      — Derive quick suggestions from user's past history
  • Prompt versioning     — Save which system prompt version generated each arch
                            for debugging

Prompt: "How do I inject past feedback into the Anthropic system prompt?"


===========================================================
PHASE 6 — EXPORT + EXTRAS                          Day 13–14
===========================================================
Tags: jsPDF, Supabase Storage, React Router

Steps:
  • Markdown export   — Convert arch JSON to structured .md file, download in browser
  • PDF export        — Use jsPDF or Puppeteer on server to render arch as PDF
  • Share link        — Generate public UUID-based URL for any architecture (/arch/:id)
  • Cost estimator    — Rough monthly cost breakdown based on chosen stack
                        (static lookup table)
  • Risk analysis     — Second Anthropic call with arch JSON, returns top 5 risks as JSON

Prompt: "Write the markdown export function for the architecture JSON"
